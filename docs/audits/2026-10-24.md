## Usability improvements

1. Preserve admin/player input after validation failures; preserve affiliate text and copy time after preview. The shared form-action hook controls reset, and successful saves still reset as appropriate. This avoids losing work or having to recopy a list.
2. Label the reading time as **Wager data as of**, explain the two-minute page check separately, and avoid promising automatic wager collection. This makes manual-import freshness understandable.
3. Show the viewer's local race time beside the authoritative Eastern date, after hydration. This helps players outside Eastern Time without changing DST-aware scheduling.
4. Put mobile movement indicators below ranks, leaving more room for masked names. Mark rejected profile claims as **Not verified** rather than **Unlinked**.
5. Give visible, accessible clipboard-failure feedback with a manual-copy path for referral codes and admin values.

The README now states that the daily 22:05 UTC cron runs at 6:05 PM EDT / 5:05 PM EST, respectively 65 / 5 minutes after the Sunday boundary. It does not collect wager totals or finalize races. Imports still establish the current race when needed.
